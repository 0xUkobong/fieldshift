# Tech Stack & 48-Hour Roadmap

## Recommended Stack
- **App framework:** Streamlit (Python)
- **Data handling:** pandas + requests
- **Charts:** Plotly
- **Deployment:** Streamlit Community Cloud or local + screen recording

## Alternative Stacks
- Gradio
- React + Flask/FastAPI

## 48-Hour Roadmap

### Phase 1 – Setup (3–4 hours)
- Create Streamlit skeleton
- Get NASA POWER API working for one location
- Define the three rotation templates and basic scoring
- Set up 2 demo locations

### Phase 2 – Core Build (6–8 hours)
- Build input form (location + priorities)
- Fetch and display POWER time series
- Create comparison cards with scores and charts
- Add farmer-friendly explanations + disclaimer

### Phase 3 – Polish (4–6 hours)
- Improve UI (cards, colors, icons)
- Make “Why this rotation?” reference real data values
- Add one extra chart or simple visualization
- Full end-to-end testing

### Phase 4 – Submission (2–3 hours)
- Record 3–5 minute demo video
- Write clear project description
- Submit on the Space Apps platform
