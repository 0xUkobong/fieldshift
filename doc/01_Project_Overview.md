# Rotation Explorer – Project Overview
**NASA Space Apps Challenge 2026**  
**Challenge:** Field Shift: Adapting Farms with NASA Data  
**Theme:** Decision-support tool for crop rotation using NASA Earth observations + local priorities

## Goal
Build a farmer-friendly web app that:
- Takes location, current rotation, and farmer priorities
- Pulls NASA data (primarily NASA POWER)
- Compares **at least 3 rotation strategies** (including the current one)
- Shows scores, charts, explanations, benefits, risks, and a clear disclaimer

## Core Requirements Met
- Uses NASA Earth observations (POWER + optional SMAP/ECOSTRESS)
- Incorporates local soil/crop characteristics and farmer priorities
- Compares multiple rotation strategies with evidence
- Farmer-centered, interpretable design
- Explicitly states the tool supports (does not replace) local expertise

## Recommended Scope for 48 Hours
- Working prototype limited to 2–3 demo locations
- Live or pre-fetched NASA POWER data
- Rule-based rotation scoring (transparent, no black-box AI required)
- Clean Streamlit UI + demo video
