# User Flow – Rotation Explorer

## 1. Landing / Location
- Enter city, region, or lat/lon
- Or select from pre-loaded demo sites (recommended for prototype)
- Optional: field size or basic soil notes

## 2. Current Situation
- Dropdown: primary current crop(s)  
  (maize, wheat, soybean, rice, cotton, vegetables, mixed, other)
- Optional free-text notes

## 3. Farmer Priorities
Checkboxes or weighted sliders:
- Conserve water / drought resilience
- Improve soil organic matter & structure
- Natural nitrogen fixing
- Reduce erosion
- Forage or supplemental income
- Market suitability / cash crop focus

## 4. Results Dashboard
Side-by-side cards for 3–4 rotations showing:
- Rotation name
- Overall resilience score
- Key charts (temperature, rainfall, moisture/stress)
- “Why suggested”
- Benefits
- Risks / data gaps
- Priority match

## 5. Details & Export
- Expandable explanations of terms (heat stress, soil moisture anomaly, etc.)
- Prominent disclaimer
- Download summary or easy screenshot support
